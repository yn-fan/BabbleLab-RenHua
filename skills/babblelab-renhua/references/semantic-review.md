# 语义复核：候选为什么要改，或为什么要留

用于复核 `extract_candidates` 生成的 `rename`、`cohesion`、`colon`、`iso3` 四类候选。候选是检查线索，不是语言错误；脚本未命中也不代表没有问题。

## 记录与上下文

1. 保留候选的 `type`、`file`、`line` 与原文片段，不覆盖原始内容或静默删掉误报。
2. 先读候选，再回到原稿核对前后句或段落。理解指称、逻辑关系或作者语气需要上下文，不能为了独立打标忽略它。
3. 无法取得足够上下文时，`label` 选“无法判断”，`disposition` 选“待核”。猜测不能作为确认依据。
4. 每条记录 `label`、`confidence`（高/中/低）、`reason` 与 `disposition`。低置信的解释不是默认改写理由。

`disposition` 表示本次任务的处置，与语言现象的标签分开：

| 值 | 使用条件 |
|---|---|
| 拟改 | 有可定位的阅读问题，能说明保真改法，且属于用户要求的范围 |
| 保留 | 现象存在，但在该处有表达作用，或超出本次编辑范围 |
| 误报 | 粗筛找到了相近字面形式，实际不符合该类现象 |
| 待核 | 事实、指称、上下文或修辞用途不足以判断 |

理由要说明该句的功能或问题，例如“否定部分保留了排查结果”，不能只写“像 AI”或“读着自然”。拟改项补一句具体改法；保留项不要求证明任何统计例外。

示意记录：

```json
{
  "type": "colon",
  "file": "article.md",
  "line": 12,
  "sentence": "导出格式：CSV。",
  "label": "定义或解释",
  "confidence": "高",
  "disposition": "保留",
  "reason": "冒号说明配置值，表达清楚，无需更换。"
}
```

## rename：同一实体或概念换指称

候选原文通常在 `para`。判断段内是否用不同的实义说法指向同一对象；代词、省略及明确的别名介绍不是要消除的问题。

| label | 含义 |
|---|---|
| 0组 | 未见同一对象的实义指称变换 |
| 1组 | 确认一次指称变换 |
| 2组 | 确认两次指称变换 |
| 3组及以上 | 确认至少三次指称变换 |
| 无法判断 | 不足以确认这些说法指向同一对象 |

这里的“组”沿用候选工作流的标签，计数单位是换指称的连接次数。三次以上是下界，不能按恰好三次算精确平均值。

同一个对象有多个名称并不自动需要改写。只有指称变化增加辨认负担、且统一后不损失含义时才拟改。先核对“产品／平台”“效率／产量”等词是否确实等同。近义动词还须检查搭配，不能机械统一。

## cohesion：段落接口的关系

候选字段为 `prev_tail` 和 `next_head`。核对它们在原稿中的真实位置，必要时读取两个完整段落。被过滤的短段、标题或代码可能位于两者之间，不能把抽样后的相邻记录当原文相邻。

按实际关系选一个标签：

| label | 含义 |
|---|---|
| 表面有连接词实际关系不清 | 连接词宣称的因果、转折、时间等关系缺少支持 |
| 明确承接 | 前后围绕同一对象或论证关系继续展开 |
| 有关但转换突然 | 同一话题域中缺了理解所需的一步 |
| 主题跳转缺少说明 | 换到了另一话题，当前上下文未交代关系 |
| 无法判断 | 候选或补读上下文仍不足 |

“明确承接”通常是正常写法。即使连续出现，也不能据此人为制造跳跃。仅在过渡语重复、关系标错或理解确实受阻时提出改法；作者有意的转场可以保留。

若展示连续长度，必须按同一文件的真实相邻接口计算。遇到抽样间隔、未判条目、被过滤内容或文件切换即中断；无法核验连续性时不报告最大连环。长度不作为质量分或身份判断。

## colon：冒号的具体用途

读取 `colon_before`、`colon_after` 与 `sentence`；被截断时查看原句。按下表从上到下选择最贴近用途的标签：

| label | 含义 |
|---|---|
| 引语或人物发言 | 人物原话、访谈体或言论引出 |
| 标题时间比例元数据或版式用途 | 标题、时间、比例、字段或来源标注 |
| 定义或解释 | 给术语、功能或概念提供内容或说明 |
| 空转提示 | 预告接下来列出几点，本身没有独立判断 |
| 结论提示 | 前半句给出明确判断，后半句展开论证 |
| 其他正文冒号 | 其他有效或未列出的正文用途 |
| 无法判断 | 上下文不足以确定用途 |

这些标签均不直接决定删改。结论提示也可能有效概括论点；列表引子可能帮助读者理解范围。只有纯提示重复、没有独立信息时才删。承担判断或承接的部分保留；直接引语不为清理句式而改。

## iso3：三个句子的骨架

候选 `sents` 保存三句。脚本可能只比较长度和标点，复核时需真正比较主语、谓语、宾语、条件及补充成分。

| label | 含义 |
|---|---|
| 高度同构 | 三句成分位置基本对应，主要替换填入的词 |
| 部分同构 | 部分结构相似，但重要成分不对应 |
| 只有词语重复句法不同 | 重复词语，句法组织不同 |
| 只有语义并列句法不同 | 内容构成并列，句法并不重复 |
| 无同构关系 | 未见相应关系 |
| 无法判断 | 句子残缺或上下文不足 |

高度同构也可能适用于演讲、比较表述、操作步骤和文学排比。要改时，保留每句独立的信息，只合并共同成分或调整语序。不能为打散三句补充案例细节，也不能删掉其中一个比较维度。

## 交付与复测

审稿模式输出问题、例句和建议；改写模式按已获授权的范围完成修改与复核，无需固定停在报告后等待下一轮。待核项可保留并注明缺少什么信息，不阻断其他已明确的编辑。

汇总时区分候选数、已复核数和各处置数，说明抽样或截断范围。标签计数不是有效问题数；不可把未审候选当零问题。复测用同样范围与口径，对照实际改动核对信息守恒。不得输出“AI 率”、作者身份判断或过检测承诺。
